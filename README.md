# Huskies Coaches Dashboard

A beginner-friendly R Shiny starter project for the Keyano Huskies men's volleyball team, ACAC, 2026–27 season.

## What's included right now

- Keyano Huskies logo and dashboard header.
- Season label: `KEYANO · ACAC · 2026–27`.
- Five match-period buttons: Most Recent Match, Previous Match, Last 5, Last 10, Full Season.
- Athletes button that opens a searchable season roster.
- Public-facing roster uses **first names only**, plus jersey number and position.
- Placeholder match metrics. No match results or statistics have been invented.

## Folder guide

- `app.R` — the main Shiny website.
- `www/` — logo and visual styling.
- `data/metadata/roster.csv` — season roster used by the app.
- `data/raw/` — place original match Excel workbooks here in future.
- `data/processed/` — reserved for clean data generated by the R pipeline.
- `R/`, `modules/`, `tests/` — reserved for the data pipeline, separate page modules and checks.

## Part A — Start with GitHub (no coding experience needed)

1. Go to https://github.com and sign in or create an account.
2. On GitHub, click **+** (top-right) → **New repository**.
3. Repository name: `keyano-huskies-dashboard`.
4. Choose **Public** if you intend to deploy with a hosting plan that requires a public repository. The app and committed data will be visible to everyone in a public repository. Do not upload confidential scouting notes or private player information.
5. Select **Add a README file** only if GitHub asks and you plan to upload this project's files over it; if a conflict appears, keep this project's README.
6. Create the repository.
7. On the new repository page, choose **Add file** → **Upload files**.
8. Open the downloaded ZIP on your computer and extract it first. Upload the *contents inside* the `keyano-huskies-dashboard` folder, not the ZIP itself and not an extra nested folder.
9. Drag the extracted files and folders into GitHub's upload area. GitHub may not preserve empty folders; that's fine. The folders with files will be created automatically.
10. In the commit message box, type `Add initial Huskies dashboard` and click **Commit changes**.
11. Confirm that `app.R`, `README.md`, `www/`, and `data/metadata/roster.csv` appear at the top level / expected folders.

## Part B — Deploy the Shiny website

The initial recommendation is Posit Connect Cloud. Hosting plan names, pricing, and GitHub integration options can change, so confirm the current account requirements on the official site before choosing a plan.

1. Visit https://connect.posit.cloud/ and sign in or create an account.
2. Create a new deployment and choose the option to deploy from GitHub, if available on your plan.
3. Connect GitHub and select `keyano-huskies-dashboard`.
4. Select the branch `main` and the file `app.R` as the app entry point.
5. Deploy and wait for the build to finish.
6. Open the public URL provided by the hosting service. Test the logo, five period buttons, and Athletes roster.
7. Keep that URL as the single link you share with coaches.

Official guide: https://docs.posit.co/connect-cloud/how-to/r/shiny-r.html

## Part C — What an update will look like later

Once the match workbook import pipeline has been added:

1. Add each new match workbook to `data/raw/` using a consistent filename, such as `2026-11-14_TeamA_vs_TeamB.xlsx`.
2. Upload/commit the file to GitHub with a message like `Add match workbook 2026-11-14`.
3. GitHub Actions will be configured to validate the workbook and rebuild the processed data.
4. The deployed app will publish the new version after checks pass.

**Important:** the automatic Excel-to-statistics pipeline is not implemented yet because the match workbooks and their sheet/column layouts have not been supplied. Until that mapping is built, the match metrics intentionally show placeholders. The roster is already connected.

## Local run (optional; do this later if you prefer)

If you want to run the app on your own computer, install R and RStudio Desktop first:

- R: https://cran.r-project.org/
- RStudio Desktop: https://posit.co/download/rstudio-desktop/

Open the project folder in RStudio, open `app.R`, and install missing packages by running this in the RStudio Console:

```r
install.packages(c("shiny", "bslib", "readr", "dplyr"))
```

Then click **Run App** above the code editor. You do not need to do this just to upload files to GitHub.

## Roster privacy / naming rule

The original workbook includes jersey number, first name, last name and position. This starter app exports only jersey number, first name and position to the public-facing roster. Other dashboard datasets should use first names only for athlete labels, as requested. Do not include last names in future public datasets unless you explicitly change that rule.
